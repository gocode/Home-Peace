# Vérifications de la première version

- Installation des dépendances et vérification de syntaxe JavaScript : réussies.
- Schéma SQL exécuté dans un PostgreSQL embarqué (PGlite) : réussi.
- Tests de sécurité : séparation entre deux familles, enfant incapable de se promouvoir parent, confirmation réservée au parent : réussis.
- Tests DOM (jsdom) : accès démonstration, création, validation, vues jour et semaine, absence de notification réelle dans la démonstration : réussis.
- Contrôle visuel dans un navigateur : non réalisé, téléchargement du navigateur indisponible dans cet environnement.
- Authentification Supabase réelle, déploiement Vercel et réception Web Push Android/iPhone : non testés, services non connectés.

Le projet est une première version à déployer et à recetter, pas un service déjà en production.
